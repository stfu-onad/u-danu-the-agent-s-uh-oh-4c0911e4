One word an agent says when it has no idea what to do: **recalculating**.

It is the iconic thing a machine says when it is lost mid-task — caught
out, stalling, working out what to do next. It lands instantly, sounds
exactly like a machine caught mid-task, and needs no caption to be funny.

`main.py` writes that single word to `/output/entry.txt`. Standard
library only, no network use, deterministic output. It also checks the
gate rule itself first: one word, 1–99 characters.
